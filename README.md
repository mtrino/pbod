# Personal Board of Directors (PBOD)

## Overview
The Personal Board of Directors (PBOD) is an advanced multi-agent system designed to function as an expert advisory team. Built upon a hierarchical supervisor-worker architecture, PBOD leverages Agentic RAG (Retrieval-Augmented Generation) to deliver highly specialized, context-aware insights, acting as a personal advisory board for complex decision-making and problem-solving.

## Architecture
PBOD utilizes a **Hierarchical Supervisor-Worker Architecture**:
*   **Supervisor Agent:** Orchestrates user queries, breaks down complex tasks, and routes specific sub-tasks to the appropriate specialized worker agents.
*   **Worker Agents:** Domain-specific experts that retrieve context, process information, and synthesize advice using Agentic RAG capabilities before returning findings to the supervisor.

## Key Technologies & Tech Stack
*   **Semantic Database:** Qdrant
*   **Relational Database:** SQLite
*   **Observability Platform:** Langfuse
*   **Evaluation Frameworks:** RAGAS, RAG Triad
*   **Data Validation:** Pydantic

## Structured Outputs & Data Validation
To ensure reliability and consistency from the LLMs, PBOD enforces a strict schema for all agent responses:
*   **Pydantic Models:** Pydantic is used extensively to define rigid data structures. All outputs generated by the worker agents and the final synthesis from the supervisor must adhere to these predefined models.
*   **Custom Validators:** Custom validation logic is built into the Pydantic models to automatically clean malformed data and catch logical inconsistencies.
*   **Hallucination Mitigation:** By strictly typing outputs (e.g., ensuring an agent returns a specific list of actionable steps rather than a conversational paragraph), the system actively forces the LLM to ground its responses, significantly reducing the risk of hallucinated advice.

## Memory Architecture
The system employs a robust **Hybrid Memory Pipeline** to maintain both state and semantic context across complex multi-turn interactions:
*   **Semantic/Vector Memory (Qdrant):** Handles dense vector embeddings for the Agentic RAG capabilities. This allows the system to perform similarity searches, retrieve relevant domain knowledge, and recall past contextual advice.
*   **Conversational/Relational Memory (SQLite):** Manages relational states, session histories, and structured metadata. This ensures the advisory team retains long-term conversational continuity and strictly adheres to user-defined constraints over time.

## Observability and Tracing
Comprehensive tracing is integrated to monitor multi-agent performance, cost, and system health:
*   **Langfuse Integration:** PBOD uses Langfuse for end-to-end observability of the entire LLM pipeline.
*   **Decorator-Based Tracing:** Native decorators (such as `@observe`) are applied directly to agent executions and critical functions. This maps out execution paths, tracks latency, measures token usage, and simplifies the debugging of complex multi-agent reasoning steps.

## Evaluation Framework
To guarantee the quality, safety, and accuracy of the advisory board's output, PBOD implements rigorous evaluation protocols:
*   **RAG Triad:** Systematically evaluates Context Relevance, Groundedness (Faithfulness), and Answer Relevance to ensure the LLM's outputs remain anchored to the retrieved data.
*   **RAGAS Integration:** Utilized to build and score against a "Golden Dataset," ensuring the pipeline's retrieval and generation capabilities meet baseline performance metrics during development.

## Roadmap & Future Development
*   **Human-in-the-Loop (HITL):** Implementing intervention checkpoints allowing the user to review, correct, or approve agent logic before final synthesis.
*   **Advanced Retrieval:** Integration of dedicated rerankers to improve the precision and ordering of retrieved context from Qdrant.
*   **Deployment:** Transitioning the local development setup to a robust, production-ready hosted environment.
*   **UI Expansion:** Building out a comprehensive user interface to interact seamlessly with the advisory board, visualize the supervisor's orchestration, and manage the hybrid memory stores.
